# Recicla Pals

Pàgina d'entrada de l'app **Recicla Pals**: «Fes una foto al teu residu i et dic on va.»

Aquesta pàgina mostra a pantalla completa l'aplicació web feta amb Google Apps Script i permet instal·lar-la al mòbil amb la seva icona («Afegeix a la pantalla d'inici»).

- `index.html`: la pàgina que obre l'app.
- `manifest.webmanifest` i les icones `*.png`: nom, colors i icones de l'app instal·lada.

Prototip no oficial. La foto de portada de l'app és de Joan301009 (Wikimedia Commons, CC BY-SA 3.0).
